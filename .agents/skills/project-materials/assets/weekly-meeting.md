# Weekly manager meeting

Help the manager decide what needs their attention this week. Write plain English Markdown that takes about one minute to read. Lead with the decision requested, its impact and the response date if one is recorded. When no decision is pending, say so and lead with the material change instead.

Use the current decision record, the effort estimate and the previous meeting's brief. Distinguish an estimate from a commitment. Close last week's question when an authorized decision resolves it. Cite the dated item, slide or cell that supports a material change.

Save a dated draft in the team's meeting folder. For a revision to the same meeting, update the decision and changes sections. Leave the chair's notes as edited. Sharing belongs to the meeting owner unless the request authorizes it.
